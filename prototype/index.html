How to read this prototype: the app frame above is the product — dark, vinyl-inspired, one accent (lime) for taste actions and one (coral) for the VS moment and likes. Demo content uses a shortened 6-round Hip-Hop run so you can reach the profile reveal quickly; the real MVP runs 16 rounds per genre across 5 seeded genres. Likes, pins, filters, and the post composer all work in-page so the board → profile pin loop can be felt, not just described.
